# Karty adresářů

Každý panel může mít mnoho adresářů jako karty.

| Klávesa | Akce |
| --- | --- |
| `Ctrl+T` | nová karta s aktuálním adresářem |
| `Ctrl+W` | zavře aktivní kartu (poslední zavřít nelze) |
| `Ctrl+Tab`, `Ctrl+Shift+Tab` | další / předchozí karta |
| `Ctrl+Shift+T` | zdvojí aktivní kartu |

Karta si pamatuje svůj adresář, řazení i filtr. Uzamčení karty drží její adresář,
i když přejdete jinam v druhém panelu. Zavřením poslední karty panel jednoduše
zůstane tam, kde je.

Karty se ukládají se sezením, takže restart vrátí adresáře, se kterými jste
pracovali — pokud jste v nastavení nevypnuli *ukládat pozici*.
