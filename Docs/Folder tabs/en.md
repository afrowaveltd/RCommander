# Folder tabs

Each panel can hold many directories as tabs.

| Key | Action |
| --- | --- |
| `Ctrl+T` | new tab with the current directory |
| `Ctrl+W` | close the active tab (the last one cannot be closed) |
| `Ctrl+Tab`, `Ctrl+Shift+Tab` | next / previous tab |
| `Ctrl+Shift+T` | duplicate the active tab |

A tab remembers its own directory, sort order and filter. Locking a tab keeps its
directory when you follow the other panel. Closing the last tab of a panel simply
keeps that panel where it is.

Tabs are saved with the session, so a restart brings back the directories you were
working with — unless you turned off *save position* in the options.
