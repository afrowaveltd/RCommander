# Directory hotlist and history

## Hotlist (`Ctrl+D`)

The hotlist is your curated list of destinations: home, project folders,
network paths. Entries can be added, renamed, reordered and given separators; the
list is stored in the configuration directory and can be edited in the dialog or
by hand in the settings file.

The hotlist is per installation, not per panel, because a destination is usually
useful on both sides.

## History (`Alt+Down`)

Every directory you visit is remembered per panel, most recent first. `Alt+Left`
and `Alt+Right` walk the history like a browser, `Alt+Down` shows the list.

History entries keep the file name the cursor was on, so returning to a
directory puts you back on the file you were looking at. Entries whose name
matches a newer entry are thinned out, which keeps the list short and useful;
the depth is configurable (30 by default).

## Selecting a hotlist entry

Choosing an entry opens it in the active panel. Hold `Ctrl` while choosing to open
it in the other panel instead, which is the quickest way to set up a two-panel
comparison.
